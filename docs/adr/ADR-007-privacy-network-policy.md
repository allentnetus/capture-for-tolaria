# ADR-007：V0.1 采用 local-first、无 telemetry 策略

- 状态：Accepted
- 日期：2026-08-21

## 背景

网页剪藏会接触用户主动选择的文章和本地 Vault。把内容上传服务器会扩大信任边界、增加隐私风险和部署成本，也不是基础文件保存所必需的。

## 决策

V0.1 不包含账号、云服务、服务器上传、telemetry、浏览历史采集、cookies 采集或后台网络抓取。Extension 仅在用户点击时读取当前页面；Helper 只在用户触发剪藏且 Extractor 已识别出正文图片时，以无凭据、受限方式下载图片；Markdown 对失败图片仍保留经过检查的 HTTP/HTTPS URL。

## 后果

- 离线保存路径清晰，用户数据留在本地。
- 无法在 V0.1 提供云同步和跨设备队列。
- 任何未来网络能力都必须另行记录域名、数据类别、授权方式和失败策略，不能隐式加入。
